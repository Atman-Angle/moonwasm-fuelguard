## 覆盖与结果

| 检查 | 结果 |
| --- | --- |
| MoonBit 单测与独立 Python 预言机 | Wasm 单测 111/111，预言机单测 17/17 |
| 具名差分 | 69 个确定性用例，其中 24 个控制流或栈边界用例。wasmoon 与 Wasmtime 分别运行原件和 Fuel v2 产物，返回值及受测状态一致 |
| 实际 MoonBit 负载 | F0 hello、F1 JSON 解析、F2 Lisp 求值、F3 SHA-256 的原件和交付产物均在两引擎正常运行，输出逐字节一致 |
| Fuel v2 临界检查 | 每引擎执行 182 份 span 和缓存差分脚本。长直线 span、长短循环、嵌套条件、`br_if`、`br_table`、回边、原生陷阱和回调重入均匹配预期。覆盖临界费用减一、等于和加一，含 i64 最大初始余额 |
| 动态、增长与栈 | 运行长度 0 和 u32 最大长度，验证静态预扣、动态附加费和增长限制的诊断顺序。校验栈审计 A ≤ C、栈和深度边界、export/start/element 重写及导入保持 |
| 拒绝路径 | 零 Fuel、超 i64 Fuel、超 31 位栈单位及深度、未知模型与 codegen 均退出 2，拒绝时无产物。另有 23 个变异拒绝用例通过 |
| 生成语料 | 种子 `270019`，5,004 个生成用例与 4,996 个变异用例。10,000 个输入哈希互异，全部完成插桩和独立校验，并在两个引擎运行。6,667 个正常返回，3,333 个按预期受控终止 |

Python 预言机从源操作的控制流图和契约权重独立计算 span。差分脚本比较
首站点、长度、静态费用的摘要，再由 `instrument verify` 检查实际 Wasm guard。
双引擎都运行同一份交付产物，额外的观察副本用于核对已发布的 Fuel 余额。
先扣整段静态费用，故预算不足时该 span 的写入和输出均不会发生。
WASI 边界还独立核对了实际 stdout 字节以及借助宿主替身保留实例时的诊断。

本模型的单次动态收费使用 u32 长度和冻结的单位权重。在可表示输入范围内，
最大的附加费用是 `64 × (2^32−1)`，加上静态基础费仍小于 i64 最大值。
用双引擎验证 u32 最大输入，用独立预言机和 MoonBit 合成权重测试覆盖数学
i64 溢出及乘法前的同站点保护分支。

生成语料的 10,000 个通过样本未产生反例。验收自测向一例注入错误预期，
成功保留同一失败签名并缩减输入。回放缩减样例时，错误预期退出 1，
正常预期退出 0。自测也验证了缺工具、未运行门槛和超时清理。

## 复现

在 Linux x86_64 文件系统的工作区运行。实测环境为 Ubuntu WSL2
`FuelGuard-S26`、glibc 2.39、Python 3.12.3、MoonBit `0.1.20261104 (940aa18)`、
wasmoon 0.18.0、Wasmtime 50.0.0、wasm-tools 1.263.0。

```bash
python3 -B integration/acceptance/check.py --group correctness --group generated \
  --group rejections --out _build/s35/acceptance/s35 --jobs 12
python3 -B integration/acceptance/self_test.py --out _build/s35/self-test-s35
```

可从已安装固定工具链的 Linux 环境单独重跑一个边界或生成样本。

```bash
python3 -B integration/fuel_cache/check.py --out _build/s35/span-repro
python3 -B integration/p1/check.py --out _build/s35/prefix-repro
python3 -B integration/generated/check.py replay --seed 270019 --index 19 \
  --out _build/s35/sample-00019
```
