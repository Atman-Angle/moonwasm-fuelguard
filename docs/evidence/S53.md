# S53 · A17 F2 热路径实验

2026-11-26。该切片沿用 [S52](S52.md) guest profile 方法，在隔离 `_build` 副本测试缓存/余额同步和 Stack v2 路线。A17 验收仍按 [FuelGuard v4](../14_FuelGuard生产规格_v4.md)，本页缩放 F2 数据只作诊断，不能替代正式 tuning 或 holdout。

## 环境与基线

MoonBit 工具链为当前开发环境的 `0.1.20261119 (738607b)`。实验副本通过将 Mooncakes starshine `0.3.0` 中旧式 `Show`/`Hash` 扩展调用改为显式 trait 调用，兼容当前编译器；该适配仅存在于 `_build` 副本，没有改动生产依赖或 ABI。基线和候选均用同一工具链、同一兼容副本构建 Wasm CLI。

诊断输入为 F2 `_start` 嵌入程序 `(fib 27)` 的副本。原始 fixture 输入仍为 `(fib 18)`，没有修改冻结数据。每个运行结果使用 Wasmtime 50 CLI 独立进程，模块通过 wasm-tools 1.263.0 验证。计时包括 CLI 启动、模块编译、实例化和执行，不与 A17 的正式采样口径混淆。

## 缓存架构实验

第一候选让所有含直接或间接调用的多 span 函数禁用 Fuel 局部缓存。该策略影响 `plan_fuel` 的缓存资格和相关白盒测试。124 项测试通过，Fuel v2 CLI 构建成功。对 fib(30) 诊断输入，该候选输出与基线 stdout 一致，产物从 26,800 B 减至 25,695 B，但 6 组交错计时中位数从 2,404 ms 升至 2,487 ms，慢约 3.5%。该方向已否定，没有进入正式源码。

第二候选只在直接自递归函数禁用缓存。124 项测试通过，CLI 构建及候选 wasm-tools 验证通过。fib(27) 候选输出与基线一致，产物从 26,800 B 减至 26,206 B。8 组交错计时基线中位数为 2,544 ms，候选为 2,647 ms，慢约 4.1%。该窄化策略也已否定，没有进入正式源码。

两项候选都通过当前隔离实现的测试和结构验证，但完整保护下性能变差。尺寸收益不足以抵偿运行时回退。

## Stack v2 路径核对

初步检查把 `pipeline.mbt` 的 `reuse_checked_bound` 参数视为 Fuel v2 Stack 路径开关，这是错误判断。FuelV2 实际调用 `apply_stack_v2`，而该旧参数只传给其他布局使用的 `apply_stack`。生产 `StackV2::body` 已自行传播 `bound`，并在支配检查证明费用足够时省略重复检查；S51 对此已有记录。

隔离实验仅把旧 `apply_stack` 参数条件扩展为 FuelV2，全部 123 项测试通过，但它没有触达生产路径。fib(27) 输出与基线均为 26,800 B，SHA-256 相同，为 `5597fce0c72e972c4e0525f92b98db45febd1d10524b5a2bd9800be238c52b01`。该产物相同只能证明本次编辑对 FuelV2 无效，不能证明 Stack v2 复用没有命中或没有性能影响。该候选不进入正式源码。

## Fuel 与完整保护差分

使用同一 fib(27) 原始输入、Fuel-only 输出和完整保护输出，在 Wasmtime 50 上进行 6 组交错运行。每个变体均为独立进程，完整保护与原始模块 stdout SHA-256 一致，为 `f27b3dde7a3b173761ff315b09b2a433b760805f339fbd89c2bba8f4d424569b`。

| 变体 | 中位数 | 六次观察范围 |
| --- | ---: | ---: |
| 原始 | 1,067 ms | 943–1,251 ms |
| Fuel-only | 2,412 ms | 2,170–2,564 ms |
| 完整保护 | 2,619 ms | 2,334–2,686 ms |

按六次均值计算，Fuel-only/原始为 `2.172×`，完整保护/原始为 `2.354×`。Growth 与 Stack 在该单一放大工作负载上的合计增量约为 `0.182×`。这说明后续优化重点应留在 Fuel 执行热路径。小样本、单负载和缩放输入不构成 A17 判定。

诊断运行文件位于 `_build/a17-stack-reuse/diag`、`_build/a17-arch-baseline/diag` 和 `_build/a17-arch-lab/diag`。相关源 fixture 与 `bench/dataset.json` 未变。当前正式 A17 状态仍为 FAIL，S49/S50 holdout 结论保持不变。生产源码未改动，下一阶段需要验证新的 Fuel 热路径实现并按 v4 重新完成 correctness 和正式性能验收。
