## 独立审查

一个独立子代理以 S27 开发前快照为基线，按 `/check` 做了只读深度审查。
子代理复核了旧布局字节兼容、调用可达闭包、动态费用和 Stack 审计，另外用
20,000 组权重与预算核对紧凑 profile 的算术，重放步骤 3b 的原始报告。

| 级别 | 发现 | 处理 |
| --- | --- | --- |
| P1 | 旧试点把跨越噪声阈值的区间归为无回退 | 报告改为区分检测到回退、阈值内和区间未定。步骤 3b 补采后撤回 |
| P2 | 试点绑定了历史构建记录，缺少实跑环境 | 记录并校验在线主机电源、Linux CPU、亲和性、栈上限和单调时钟，重放复核该记录 |
| P2 | 交付校验可能忽略非预期形式的共享扣费调用 | 已识别调用的参数形状或 compact profile 不合约即报错。新增合法／异常站点的白盒测试 |
| P3 | 旧两布局的 Stack C 一致性断言范围缩小 | 恢复原有完整 C 序列比较，单列 compact 共享 helper 的 64 单位预算 |

布局版本和 [编码说明](../implementation/join-span-compact.md) 已单独记录。费用
模型语义仍是 `fuel-v1.2`。该版本的源码指纹覆盖 `join_fuel.mbt`，因新增布局分支
而更新。审查对照的 9 个场景共 18 个原版和 `join-span-cached` Wasm 哈希与 S27
基线一致。

## 复现

从归档解包相应源码到 Linux 本地仓库。构建入口除了逐阶段 native 账本，还用
Wasm CLI 独立生成并要求输出逐字节一致。脚本用 wasm-tools 校验输出，并以
交付校验核对 sidecar。保留 SHA-256、命令、阶段、用例及进程 RSS。

```bash
export MOON_HOME=/root/s26-frozen-moon
export PATH="$MOON_HOME/bin:/opt/fuelguard-s26/bin:/usr/bin:/bin"
export LC_ALL=C
common=(--frozen-workers /root/fuelguard-s26-locked/_build/s26-pilot-final
        --host-record /mnt/d/moonwasm-fuelguard/_build/s26-tools/host.json
        --wasmtime-c-api /root/s26-tools/wasmtime-v50.0.0-x86_64-linux-c-api)

# S27 工作树
python3 -B bench/run.py --compare-join-cached --build-only --out _build/s28/baseline-run "${common[@]}"
# 应用每步的源码快照后，分别用 step1、step2、step3、step3b 作输出目录
python3 -B bench/run.py --compare-join-compact --build-only --out _build/s28/step2 "${common[@]}"
python3 -B bench/s28.py _build/s28/baseline-run _build/s28/step1 \
  --before-layout join-span-cached --out _build/s28/pair1 > _build/s28/pair1-report.json
python3 -B bench/s28.py _build/s28/step1 _build/s28/step2 \
  --out _build/s28/pair2 > _build/s28/pair2-report.json
python3 -B bench/s28.py _build/s28/step2 _build/s28/step3 \
  --out _build/s28/pair3 > _build/s28/pair3-report.json
python3 -B bench/s28.py _build/s28/step2 _build/s28/step3b \
  --out _build/s28/pair3b > _build/s28/pair3b-report.json
python3 -B bench/run.py --compare-join-compact --build-only --out _build/s28/a20-repeat "${common[@]}"
PATH="$PATH:/root/fuelguard-s26-optimization/_build/wasmoon-0.18.0-test-source/bin" \
  python3 -B integration/acceptance/check.py --group correctness --group generated --group rejections \
  --jobs 6 --codegen join-span-compact --out _build/s28/acceptance-compact
```

步骤 1 的构建实跑同时采样了旧布局与本步布局，当次命令省略 `--build-only`。
上列 `pair1` 是独立复测。历史 `pair1`–`pair3b` 由 `step3b-source.tar` 中的
旧版脚本用 `--replay` 重建报告。新脚本的重放增加了 `timing-environment.json`
校验，适用于修补后补采生成的证据。
