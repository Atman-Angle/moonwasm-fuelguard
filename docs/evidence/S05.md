# S05 证据：确定性索引、函数事实与插桩计划

日期：2026-11-11

## 交付

- `analysis.mbt` 提供只读 `ModuleIndex`、`FunctionFacts`、`MeterSite`、`SemanticPlan`、`FunctionPlan` 和 `InstrumentPlan`。
- 模块索引按 Wasm type/import/function/table/memory 的原始密集顺序建立；定义函数索引从导入函数数之后开始，追加计数固定为 0，后续 pass 只能追加。
- 函数指令采用结构化前序编号，记录控制深度、循环数、local 数、参数数和 fuel-v1 静态/动态事实。遍历使用显式 `Work` 栈，宿主递归深度不随恶意嵌套增长。site ID 按函数索引和原始前序分配，从 1 开始，0 保留。
- 语义计划、候选 `InstrumentPlan` 与最终 `StackLayout` 分离；候选固定签名、模板、追加 local 数量、输出容量和索引起点，计划生成只产生新的数组，不修改源 `Module` 的表达式或已有索引。`output_capacity` 是确定性的上界，成本常量填充不改变结构。
- export、start 和固定 element 函数引用被登记，为后续 Stack wrapper 改写提供稳定引用清单。
