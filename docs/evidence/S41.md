## 实现

- S41 的 Fuel v2 报告使用 v2 schema。调优报告输出 `tuning_results`，最终 A17/A19 固定为
  `NOT_RUN`。独立报告只有在完整记录和冻结凭据通过校验后才能给出 `FINAL_PASS` 或 `FINAL_FAIL`。
- 冻结记录绑定申报书、源码文件账本、实际 CLI 与构建/计时 worker、工具链、数据集和配置。执行
  holdout 前重放调优档案并核验冻结身份，随后使用冻结二进制。正式计量的 Wasm 需与 CLI 的隐式
  默认布局产物逐字节一致。报告绑定输入、环境、账本和产物哈希。旧 S37 缺少新增的冻结身份字段，
  仍可重放为调优证据。
- 仅代表应用参与 A17/A19。A17 按引擎和窗口判几何均值，并保留逐应用中位数与 p95 判定；
  A19 按 10 KiB 分界执行申报书公式。微基准、Fuel-only、编译、构建、RSS、sidecar 和 A20 单列。
- A17 按配对整进程做 10,000 次百分位 bootstrap，完整保留每个进程的采样序列。调优沿用
  3 进程，独立验收在看数据前固定每单元 20 进程，每个 300 个计时样本，避免事后追加
  样本影响名义置信度。此处是内部测量设计，置信区间覆盖率依赖进程间独立性。
