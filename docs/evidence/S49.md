# S49 · 申报书 v2 体积门槛与独立 holdout

2026-11-25（北京时间）。本切片将申报书 v2 体积门槛同步到 [生产规格 v4 §3](../14_FuelGuard生产规格_v4.md#3-体积预算规范正文) 与性能/负载验收入口，并在冻结候选上执行正式独立 holdout。体积上限按原件字节数统一计算：原件 `>= 10 KiB` 时产物 `<= 3×` 原件；原件 `< 10 KiB` 时新增 `<= 15 KiB`。sidecar 单独报告。

## 变更与范围

`bench/performance_evidence.py` 提供共享 `size_limit()`，供 `bench/s28.py`、`integration/fuel_v2/workloads.py` 及验收报告使用。边界测试覆盖 `10 KiB - 1` 与 `10 KiB`。v4 §3 说明新门槛来源，并把旧门槛及其算术风险结论标为历史记录。没有修改 CLI、MoonBit ABI、计费规则、配置或外部依赖。

## 正式独立验收

正式 holdout 对冻结候选运行 20 个独立进程组，每组 300 个样本，使用 10,000 次配对整进程 bootstrap，以 95% CI 上界判定。原始文件 `samples.jsonl` 有 330,480 行，SHA-256 为 `100183973a49b674143e6aed0dde80bcf3ae0100165ce69b68628ef982808c98`。无 borderline cells。

| 门槛 | 正式结果 | 观测 |
| --- | --- | --- |
| A17 性能 | **FAIL** | Wasmoon hot/lifecycle 几何均值比 CI 上界为 1.706× / 1.732×；Wasmtime 为 2.214× / 2.228×，后两项超过 2×。 |
| A19 体积 | **PASS** | `json_parse` 12,628 → 30,577 B（上限 37,884 B）；`lisp_eval` 10,268 → 26,280 B（上限 30,804 B）；`sha256_hash` 10,219 → 22,040 B（上限 30,657 B）。 |
| A20 构建诊断 | **NOT_RUN** | 正式 holdout 报告没有运行 A20。独立 tuning 中 A20 为 PASS，4 MiB 最大输入 5,092,039,796 ns、494,832 KiB；此 tuning 结果不替代正式 holdout 结果。 |

12 个应用窗口的逐负载中位数及 p95 比值 95% CI 上界都不超过 3×。因此正式结论为 `FINAL_FAIL`，唯一失败门槛为 A17；体积新门槛已通过。三项 sidecar 为 640、641、640 B，均单独列账。

正式 holdout 使用的新应用输入 SHA-256 为 `4229a04f9eb2c8dd2e1d5579b2ba38987585eacbdfa36047ee848dc49b42446e`（json_parse）、`68ff0b1361bfe554407b295c2d211fa9c75e3b250d21241703f7b897db0baa21`（lisp_eval）和 `270706ce949674f5480b82b212e415bbb88c0d440d5ee2c5d1a33941212b06b8`（sha256_hash）。候選源码快照 SHA-256 为 `621a33c00cb9a022bfca80dbc61d3b5a75930e6ae85c85158a215ec57382a9a0`，HEAD 为 `60100c21c77e3e1fe159e21c73d76bddde7e8894`。独立工具为 MoonBit 0.1.20261104、wasm-tools 1.263.0、Wasmtime 50.0.0；完整哈希见归档报告。

Windows 主机记录 CPU 为 Intel Core Ultra 9 185H、22 个逻辑处理器、Windows build 26300、平衡电源计划。`Win32_Battery` 未返回设备，记录中的 `ac=true` 是按采样时供电状态作的操作性假设，runner 本身未强制检查该字段。

## 复现与证据

正式测量在 `FuelGuard-S26` 中按冻结 tuning 数据和候选身份执行；实际命令、退出记录见归档 `s49-holdout-commands.jsonl`。完整 Linux 运行目录保留在 `/root/fuelguard-s49-run/_build/s49-holdout`，可用下列命令独立重放：

```powershell
wsl -d FuelGuard-S26 --exec bash -lc 'cd /root/fuelguard-s49-run && python3 -B bench/summarize.py _build/s49-holdout --out _build/s49-holdout-report-replay-s49-doc.json'
```

重放输出为 `performance_scope=holdout`、`A17=FAIL`、`A19=PASS`、`performance_verdict=FINAL_FAIL`。报告 SHA-256 为 `036036977882fe751dd1e49187c8b7d0f15ddbd481329f13672083b39e7bdcc8`。证据及原始样本位于 [`_build/s49-formal-archive`](../../_build/s49-formal-archive)，其中包括 tuning 和 holdout 的样本、报告、环境、冻结身份、命令、构建账本、体积账本和完成记录。holdout `finished.json` 对样本、环境、命令、构建和体积账本分别记录哈希。
