## 6. 范围冲突处理（含用户决策）

1. **SIMD**：F1/F2/F3 全部发射 16 条 SIMD 指令与 v128 类型。核查 `moon build --help`：只有 `--target`、`-g/--debug`、`--strip/--no-strip`，**无关闭 SIMD 的选项**。因此无法走“调整构建”路径。
   - 决策：用户于 2026-11-10 选择“纳入观测到的最小子集”。已写入支持矩阵第 4 节，并同步 05/06/09/12/07/08/README。relaxed SIMD 与其余 SIMD（含 `v128.const`）仍 DENY。
   - 影响：S04 权重表 +16 条；S10 v128 按 16 字节计入栈成本；S16 双引擎必须执行 SIMD 路径；S09 增加拒绝用例。
2. **生态包旧格式**：下列候选因自身或传递依赖仍用 `moon.mod.json`，被当前工具链拒绝（`Failed to resolve the module dependency graph`），未采用：
   - `gmlewis/json@0.15.0`、`jinser/json@0.0.1`、`Guest0x0/dregex@0.0.1`、`bobzhang/html_parser@0.1.0`、`kawaz/unicodegrapheme@0.1.0`
   - `bobzhang/jsonl@0.2.0`（经 `moonbitlang/async`）、`hackwaly/regex@0.0.1`（经 `moonbitlang/quickcheck@0.9.8`，另带 deprecated `moonbit-community/debug@0.1.3` 警告）
   - 处理：不修改第三方源码、不手改 vendored 元数据、不运行 `moon fmt` 迁移他人包；改用可干净解析的真实包。此为构建格式不兼容，非插桩支持冲突，未用容易样例替换目标兼容性。
3. **无真实证据的特性**：`memory.init`/`data.drop`、externref table 增长、`ref.null`/`ref.is_null` 标为 CONDITIONAL，必须由 S07/S08 + S16/S17 合成用例补齐六项覆盖后才可声称支持。
4. **Linux 缺失**：`wsl.exe -l -v` 只有 `docker-desktop`（Stopped）。不得冒充已配置 Linux 开发环境；双引擎列全部 NOT_RUN，交 S02。

## 附录 A：解析/验证探针源码（scratch，未提交）

位置 `_build/probe/decode_check/`，`moon.mod` 导入 `jtenner/starshine@0.3.0`，包 `p/moon.pkg`：

```text
pkgtype(kind: "executable")

import {
  "jtenner/starshine/binary",
  "jtenner/starshine/fs" @sfs,
  "jtenner/starshine/lib",
  "jtenner/starshine/validate",
  "moonbitlang/core/env",
}
```

`p/main.mbt`：

```moonbit
///|
fn main {
  let args = @env.args()
  if args.length() < 2 {
    println("usage: decode-check <file.wasm>")
    return
  }
  let path = args[args.length() - 1]
  let bytes = match @sfs.read_file_bytes(path) {
    Ok(b) => b
    Err(e) => {
      println("read-error " + e)
      return
    }
  }
  println("file=" + path + " bytes=" + bytes.length().to_string())
  match @binary.decode_module(bytes) {
    Err(e) => println("decode-error " + e.to_string())
    Ok(m) => {
      println("decode-ok")
      match @validate.validate_module(m) {
        Ok(_) => println("validate-ok")
        Err(e) => println("validate-error " + e.to_string())
      }
      let funcs = match m.code_sec {
        Some(@lib.CodeSec(bodies)) => bodies.length()
        None => 0
      }
      println("defined-functions=" + funcs.to_string())
    }
  }
}
```
