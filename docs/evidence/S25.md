## 实现

1. **费用表**：`cost_model.mbt` 摘除全部 SIMD 条目（base-2 Prefix 的 14 条 +
   Barrier 表的 v128.load/store）；`cost_model_wbtest.mbt` 权重断言改为 16 条
   逐类拒绝断言。拒绝沿用既有 UnsupportedFeature 路径。
2. **值类型与 opcode 门禁**：`production_policy.mbt check_value_type` 拒绝
   VecTypeValType；`preflight.mbt` 0xFD 分支删除 16 条豁免清单，全部 SIMD
   opcode 拒绝（relaxed 有独立消息）。
3. **栈测试**：`stack_analysis_wbtest.mbt` 的 v128 用例改为 i64 结构等价
   （locals=2/operands=2/A=12，由模型语义推导并实测吻合）+ SIMD 拒绝断言 +
   stack_units 向量条款模型单测（保留 stack-v1 防御性深度，不触发栈模型版本
   变更）。
4. **负载重建**：三个 fixture 改为自持标量实现并移除库依赖（moon.pkg/moon.mod
   清空 import）：
   - `json_parse`：JSON5 结构扫描器（注释/单双引号/裸键/转义含 \xHH 与
     \uHHHH 代理对/尾逗号/整数与浮点标量求值），不物化字符串，结构校验和
     每轮 44642，期望输出 `json5 rounds=200 checksum=8928400`。
   - `lisp_eval`：span 比对符号的 Lisp 解释器（define/lambda/if/begin/
     +/-/</=，可变绑定节点支持递归 define），输出 `Number(2584)\nNumber(0)`
     与冻结记录一致。
   - `sha256_hash`：自实现 SHA-256（UInt 旋转、生成法 K/H 常量），摘要与
     冻结记录 cfd7e96b613a248f 逐字节一致，checksum=132768；新增跨尺寸
     wbtest（1/3/55/56/63/64/65/4096 与 hashlib 全一致）。
   期望 stdout 变更：F1 新 checksum；F3 第二行由 hex 改为 8 个摘要字十进制
   （`words=...`）；F2 不变。
5. **语料重冻结**：`bench/dataset.py` 更新 F1/F2/F3 摘要与期望输出；
   `bench/dataset.json` 重新冻结（SHA-256
   480f49811c5cf2a43262ce2e9aebb0198aecf0d9a360942a44880a8ed830fc45）；旧清单
   保留为 `bench/dataset-v1-simd.json` 仅作历史。holdout 变异标记
   （'alpha'/'gamma'、round 计数、fib/count 参数）在新源中恰好出现一次。
   holdout-json 期望 10405780 经实证构建核对（与字符和推算一致）。
6. **集成脚本**：`recipes.py` 移除 simd 家族；`reject.py` 增加 16 条 SIMD
   逐类拒绝用例；`corpus/check.py` simd_path 改为 assert_no_simd（每负载
   反汇编零 SIMD 审计）、F2 陷阱 site 断言改为运行时捕获 + 跨引擎/coredump
   一致性、wide-shallow 转 i64 等压并按实测重锚（C=646、叶调用 site=1539、
   入口 site=2）；`runtime/check.py` 共享 FIXTURES/BASELINE_HASHES 更新；
   `runner/check.py` wide-frame 512 v128→1024 i64（栈单位不变，
   accepted_depth=86 保留）；`stack_pass/check.py` direct/recursion/
   typed_growth 转 i64；`stack_probe/fixture.py` 转 i64（数据段 8 字节步长）；
   `manifest/check.py` 移除 v128 函数、追加非 SIMD 多结果函数保留
   multi-value 覆盖；`policy/check.py` typed-stack 转 i64 并以本地实测重锚
   （fn0 A=19 C=142）。
7. **文档**：support-matrix.md 第 4 节改写为全部拒绝记录（含 2026-11-10 纳入
   与 2026-11-18 作废的决策轨迹）；docs/05/06/08/09/12、docs/07（历史分片
   追加作废注记）、README 同步口径。
