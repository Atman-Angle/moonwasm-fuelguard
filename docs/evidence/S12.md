# S12 完整生产管线与模块不变式验收

执行日期为 2026-11-16，Git 基线为 `b6a4783`，使用当前工作区。范围为 docs/07 S12 指定的 A01–A11、A15、A16 和 A23 核心组合。

## 生产管线

通过输入检查和 Wasm 验证后，从原模块固定计费站点、追加 local、Growth helper 索引、间接签名和入口包装映射。Fuel 生成静态及 bulk 动态计费并验证，Growth 按计划将原始 grow 改写为 helper 调用并验证，Stack 预留原始调用边界的 `C`、生成入口包装并验证。三阶段共用 Fuel 创建的诊断 global、原始站点及索引映射。生成 helper 从原函数索引末尾追加，其调用不进入原始调用预算序列。

最终审计比较 import 名称、类型和顺序，原类型、函数签名索引、global 和 local，内存、表和数据声明，以及 export、start、element 的计划目标。只追加 ABI 指定的两个诊断导出。遍历最终生成代码核验每行 `A ≤ C`，添加模型标记后在编码前再验证。白盒测试把一个导出重定向到可通过 Wasm 验证的原函数，最终审计拒绝这个绕过包装的目标。重复运行保留源 AST 的编码字节。

CLI 与 `Pipeline::builtin` 的默认 `production-v1` 要求正数 Fuel、栈单位和逻辑深度。源模块含 memory/table 时还需要相应上限，导入继续按全名匹配。缺项时退出 2。S12 当时的 CLI 回归验证了失败运行不会创建新产物或破坏已有文件。迁移方式：

- 完整保护同时设置 `--max-stack-units`、`--max-call-depth`，并按输入提供资源限制和导入允许项。输出含 `production-v1|fuel-v1|diagnostics-v1|metering=per-instruction|growth=growth-v1|stack=stack-v1`。
- `--profile fuel-growth-v1` 保留原 Fuel/Growth 与输入策略，可配合 `--stack-layout` 做审核。输出独立 profile 标记 `fuel-growth-v1`，未启用运行时栈或深度预算。更早的 `--profile legacy` 也显式标记并复测。
- 自定义 `Pipeline::new` 结果会注明 `experimental custom passes`。白盒用例核验自定义组合没有内置标记和布局证明，伪造内置标记被拒绝。

## 复现

实测为 x86_64 Ubuntu 24.04 WSL2、glibc 2.39，栈软硬限制均为 8,192 KiB。工具为 wasmoon 0.18.0、Wasmtime 50.0.0（`max-wasm-stack=524288`）、wasm-tools 1.263.0、MoonBit 0.1.20261104（940aa18）。用 S02 环境中锁定的工具运行。

```bash
set -e
export LC_ALL=C
ulimit -s 8192
mkdir -p _build/s12
python3 integration/pipeline/check.py > _build/s12/run.log 2>&1
python3 integration/stack_pass/check.py > _build/s12/stack.log 2>&1
python3 integration/policy/check.py > _build/s12/policy.log 2>&1
python3 integration/growth/check.py > _build/s12/growth.log 2>&1
bash scripts/check-cli-failures.sh > _build/s12/cli.log 2>&1
bash scripts/check-runtime-linux.sh > _build/s12/runtime.log 2>&1
```

主矩阵中 wasmoon 和 Wasmtime 各运行 35 个用例，均退出 0。wasm-tools 独立校验 41 个模块，其中 34 个为完整保护产物、2 个为兼容产物。22 个拒绝用例均退出 2 且未生成输出。S08、S09/S10、S11、S02 和 CLI 失败路径回归命令均退出 0。

Windows PowerShell 7 上使用 MoonBit 0.1.20261016（1af328f）执行 `moon info`、`moon fmt`、`moon fmt --check`、`moon check --target wasm --deny-warn` 和 `moon test --target wasm`，指定 `--target-dir _build/s12-pwsh`。MoonBit 测试 84/84，`python -m unittest discover -s integration/fuel_oracle` 9/9，`git diff --check` 退出 0。
