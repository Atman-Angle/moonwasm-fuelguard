## 恢复测试环境

交付目录保留了官方 RC 原始下载包和 core 包，用于 `latest` 更新后重建相同环境。从 Linux 文件系统内的空目录恢复工具链，并把包索引快照解到独立的 `MOON_HOME`。下例的 `RELEASE_DIR` 是交付目录的绝对路径。随后从迁移指南的本地解包继续，包管理器会按快照获取依赖，在应用补丁前可以核对依赖 ZIP 的哈希。

```bash
export MOON_TOOLCHAIN_ROOT="$PWD/moonbit-1.0-rc"
export MOON_HOME="$PWD/moon-home"
mkdir -p "$MOON_TOOLCHAIN_ROOT" "$MOON_HOME/registry"
tar -xf "$RELEASE_DIR/toolchain/moonbit-linux-x86_64.tar.gz" -C "$MOON_TOOLCHAIN_ROOT"
tar -xf "$RELEASE_DIR/toolchain/core.tar.gz" -C "$MOON_TOOLCHAIN_ROOT/lib"
ln -s moon "$MOON_TOOLCHAIN_ROOT/bin/moonx"
chmod +x "$MOON_TOOLCHAIN_ROOT"/bin/* "$MOON_TOOLCHAIN_ROOT/bin/internal/tcc"
export PATH="$MOON_TOOLCHAIN_ROOT/bin:$PATH"
moon -C "$MOON_TOOLCHAIN_ROOT/lib/core" bundle --warn-list -a --all
moon -C "$MOON_TOOLCHAIN_ROOT/lib/core" bundle --warn-list -a --target wasm-gc --quiet
tar -xf "$RELEASE_DIR/evidence/mooncakes-index-dd77d32.tar.gz" -C "$MOON_HOME/registry"
```
