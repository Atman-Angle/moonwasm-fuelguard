## A20 诊断试跑

以 `bench/dataset.py::build_scale` 生成 4 MiB、4,096 函数、1,048,576 指令样本，
使用 WSL `FuelGuard-S26` 的 `moonrun`，并绑定 CPU 4。对照 CLI 为归档 S37 CLI，
候选 CLI 是本轮 Windows 构建件。诊断复跑读取
`resource.getrusage(RUSAGE_CHILDREN).ru_maxrss`，旧 CLI 为 1,024,340 KiB，本轮 CLI
为 635,036 KiB。该单次配对的差异很大，说明此诊断方式不足以支持前后结论；两者的
输出 Wasm 哈希相同，正式 A20 状态仍是 NOT_RUN。

复现命令在 Windows PowerShell 下先生成输入：

```powershell
wsl.exe -d FuelGuard-S26 -- python3 -c 'from pathlib import Path; from bench.dataset import build_scale; build_scale(Path("/mnt/d/moonwasm-fuelguard/_build/a20-probe/build-4096.wasm"), 4096, 1048576, 4194304)'
wsl.exe -d FuelGuard-S26 -- mkdir -p /root/fuelguard-s36-ticket007/_build/a20-probe
wsl.exe -d FuelGuard-S26 -- cp /mnt/d/moonwasm-fuelguard/_build/a20-probe/build-4096.wasm /root/fuelguard-s36-ticket007/_build/a20-probe/build-4096.wasm
wsl.exe -d FuelGuard-S26 -- cp /mnt/d/moonwasm-fuelguard/_build/wasm/release/build/cmd/instrument/instrument.wasm /root/fuelguard-s36-ticket007/_build/a20-probe/current-instrument.wasm
```

输入复制到 WSL Linux 文件系统后，对每个 CLI 分别执行以下 Python 调用。候选调用使用
`current-instrument.wasm` 和 `current-rerun2`；对照调用使用
`/root/fuelguard-s36-ticket007/_build/s37-formal-initial/instrument.wasm` 和
`previous-rerun2`。

```python
import pathlib, resource, subprocess
root = pathlib.Path("/root/fuelguard-s36-ticket007/_build/a20-probe")
p = subprocess.run([
    "taskset", "-c", "4", "/root/.moon/bin/moonrun",
    str(root / "current-instrument.wasm"), str(root / "build-4096.wasm"),
    "-o", str(root / "current-rerun2.wasm"),
    "--fuel", "9223372036854775807", "--max-stack-units", "100000",
    "--max-call-depth", "128",
], text=True, capture_output=True)
rss = resource.getrusage(resource.RUSAGE_CHILDREN).ru_maxrss
(root / "current-rerun2.log").write_text(
    p.stdout + p.stderr + f"exit={p.returncode} maxrss_kib={rss}\n",
    encoding="utf-8",
)
print(p.stdout, "exit", p.returncode, "maxrss_kib", rss)
```

对照复跑将上述调用中的 CLI、输出和日志分别改为表中的 S37 CLI、
`previous-rerun2.wasm` 和 `previous-rerun2.log`。
CLI 不覆盖已有产物；重复执行时给输出与日志换一个未使用的后缀，例如
`current-repeat.wasm` / `current-repeat.log` 和
`previous-repeat.wasm` / `previous-repeat.log`。
