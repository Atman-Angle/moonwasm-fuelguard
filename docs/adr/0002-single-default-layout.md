# 收敛到单一默认布局

A18 布局比较已通过并冻结结论：热路径必须内联（共享 charge helper 在热路径上实测 12–16× 回退，round-3 再证 75–85% 回退；合并 span + 函数内缓存 + 打包栈 + 支配检查复用是最优组合）。决定：生产只维护 compact v2 血统的一个默认布局，P0/P1/P2/p2-prefix/join-span/join-span-cached 归档为已完成的比较数据，不再进入回放、账本和后续证据流程。申报书要求的内联/共享/混合比较由 A18 的冻结记录满足，不需要以多布局并存的形式继续存在。

代价：后续如果冻结结论被推翻（例如新引擎/新负载证明其它布局更优），需要按新 profile 重新走 A18 流程。
