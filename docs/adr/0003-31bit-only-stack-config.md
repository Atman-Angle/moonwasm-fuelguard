# 栈/深度配置以 31 位打包为唯一支持域

打包栈预算要求"两个 Stack 上限和所有 C 都能容纳于 31 位正数"，超出时现行实现回退到两个 i64 计数器路径。决定：超 31 位可表示范围的 `--max-stack-units/--max-call-depth` 配置在解析时明确拒绝，删除双计数器回退路径及其测试。依据：认证语料的统一 C(f) 在几十单位量级，31 位余量巨大；申报书与 09 均已确立"超出认证配置拒绝生产声明"的处理原则，S25 拒绝全部 SIMD 是同一逻辑的先例。代价：配置极大上限的用户得到拒绝而非慢速支持。

v128 的 16 字节栈计入规则保留：v128 作为 local/参数类型不在当前拒绝域内，规则仍可达。
